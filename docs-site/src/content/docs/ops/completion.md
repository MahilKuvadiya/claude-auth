## `completion`
Outputs a bash or zsh completion script that tab-completes commands **and** saved account names.

```bash
claudex completion zsh >> ~/.zshrc     # or: bash
```

## `commands`
Prints the grouped cheat-sheet of every command in the terminal.

```bash
claudex commands
```
