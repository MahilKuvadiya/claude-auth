**claudex** manages multiple Claude Code accounts on one Mac — like `gh auth switch`, but for
Claude Code. Save each account once, then flip between them instantly; pool them behind one
auto-failover proxy; keep an idle session's prompt cache warm; and track rate-limit usage across
all of them — without ever logging out and back in.

## Why it exists

A Claude Code login isn't one token in one place. It's split across **two** locations:

| What | Where | Contains |
|------|-------|----------|
| **Secrets** | macOS Keychain (`Claude Code-credentials`) | OAuth access/refresh tokens |
| **Identity** | `~/.claude.json` → `oauthAccount` | email, organization, account UUID |

Swapping only the token leaves the app convinced it's still the old account. A correct switch swaps
**both, atomically** — which is exactly what claudex does.
