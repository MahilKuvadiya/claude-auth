login · add · list · current

Save each account once.

add saves whoever you're logged in as; login drives the real browser flow and saves the result under a name. list shows them all, current the active one.

names default to the email prefix — no token pasting, ever.

claudex add · login · list

switch

Flip accounts in one command.

A login is two things — the token in your Keychain and the identity in ~/.claude.json. claudex swaps both, atomically, so the app never gets confused about who it is.

watch the active dot jump — no logout, no browser.

autoswitch

Let it hop for you.

Hooks watch your usage in the background and switch to a fresher account the moment you cross your threshold — but only when you're idle, so it never interrupts a turn.

round-robin or most-headroom strategy, your call.

pool

Hit a rate limit? Keep going.

Point Claude Code at one local proxy. Every request flows through your active account — and the instant it hits 429, the proxy retries the same request on another. Mid-conversation. No restart.

stateless API → any account can serve any turn. ↓

pool join · use · members

Pool with friends — no server.

Everyone's token lives encrypted in one free JSON blob; each person runs the same local proxy. Pick whose account serves you and switch live — running sessions follow on their next request.

client-side encrypted · tokens never touch a server in the clear.

sessions · keep-warm

Step away for an hour — come back cheap.

Claude Code's cache lasts ~1 hour idle; leave a session longer and the next turn re-sends the whole conversation at full price. keep-warm replays a chosen session as a cheap cache read every ~50 min, so its cache never goes cold.

find it with sessions, warm it by id or project · ~0.1× the context per ping.

refresh

Keep every token warm.

Short-lived access tokens expire fast. refresh renews the stored copy of your inactive accounts so usage stays live and a switch never lands on a stale token.

also runs automatically before you leave an account.

doctor

One command, full health check.

Verifies the Keychain, your live credential, every saved token, hooks, and whether a newer version is out — then tells you exactly what to fix if anything's off.

green means go.

update

Updates itself, safely.

Pulls the latest version from GitHub, verifies it parses as valid Python, then atomically swaps it over the running file. Your saved accounts live elsewhere, untouched.

--check just tells you if there's something new.

claudex update
$ claudex update --check

v1.10→ v1.11 update available
