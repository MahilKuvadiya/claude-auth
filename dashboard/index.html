Under the hood

A local proxy doing quiet, careful work.

Traffic to Anthropic never leaves the developer's machine. claudex only decides which pooled seat carries each request.

Auto-failover

A rate-limited seat rests; the same request retries on the next one.

Session pinning

Pin one workspace to one seat so the prompt cache stays warm.

Targeted join links

Each invite is bound to one email and works exactly once.

Token custody

Refresh tokens live server-side; nothing sensitive lands on a laptop.

Live metering

Every token — input, output, cache — counted as it flows.

Loopback-only

Binds 127.0.0.1; if it ever fails, Claude Code talks to the API directly.
